# 172M Preflight Calculator

Takeoff/landing, weight & balance, fuel, climb, winds aloft, terrain and weather planning for a Cessna 172M (2300 lb), built from the POH.

Live site: https://bullettacos.github.io/172m-preflight/

Planning aid only. Verify against the POH and current weight & balance; the pilot in command is responsible for the final numbers.
